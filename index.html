Privacy and data

V2 stores memories, notes, tasks and settings in this browser's local storage. They are not automatically uploaded to GitHub or an AI provider. Clearing browser data may erase them. Export a backup regularly.

What this version can and cannot do

V2 is a local-first assistant with programmed responses, searchable personal memory and local utilities. It is not connected to a large language model, live web search, email, calendar or external services. Voice recognition and speech depend on browser and Android support; some browser speech services may require internet access.
